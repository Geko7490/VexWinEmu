# Third-party components

VEX Win uses [Winlator 11.2 by BrunoSX and contributors](https://github.com/brunodev85/winlator), with the Android app source pinned to [a030f552f452158a2db64fdb32b490fa19c0b48d](https://github.com/brunodev85/winlator-app/tree/a030f552f452158a2db64fdb32b490fa19c0b48d). The LGPL-2.1 license from that source is included as `LICENSE` and in the APK. VEX changes to that source are in `patches/vex-runtime.patch`.

The build retains the packaged assets and native sources from that revision. See the [upstream credits](https://github.com/brunodev85/winlator-app/blob/a030f552f452158a2db64fdb32b490fa19c0b48d/README.md) and the source projects for [Wine](https://www.winehq.org/), [Box64](https://github.com/ptitSeb/box64/tree/v0.4.4), [Mesa](https://gitlab.freedesktop.org/mesa/mesa), [Vortek](https://github.com/brunodev85/vortek), [Gladio](https://github.com/brunodev85/gladio), [DXVK](https://github.com/doitsujin/dxvk), [vkd3d](https://gitlab.winehq.org/wine/vkd3d) and [cnc-ddraw](https://github.com/FunkyFr3sh/cnc-ddraw). The upstream asset archives may contain additional third-party components. The first debug build is for device testing. A complete inventory and corresponding-source verification for each prebuilt component are pending for the public release.
